
# Karthik Reddy M — Portfolio

My personal portfolio website. Built with plain **HTML, CSS, and JavaScript** — no build step, no dependencies.

🔗 **Live:** https://kartik-reddy-m.github.io

## Features
- Responsive, mobile-first layout
- Light / dark theme toggle (remembers your choice)
- Smooth scroll-reveal animations
- Sections: About, Skills, Projects, Education, Certifications, Contact
- Downloadable résumé

## Structure
```
kartik-reddy-m.github.io/
├── index.html
├── css/style.css
├── js/script.js
└── assets/Karthik_Reddy_M_Resume.pdf
```

## Run locally
Just open `index.html` in a browser, or serve it:
```bash
python -m http.server 8000
# then visit http://localhost:8000
```

## Deploy to GitHub Pages
1. Create a repo named **`kartik-reddy-m.github.io`** on GitHub.
2. Push these files to the `main` branch.
3. In the repo: **Settings → Pages → Source → Deploy from branch → `main` / root**.
4. Your site goes live at `https://kartik-reddy-m.github.io` within a minute.
